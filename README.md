# Your Business Planner Mobile

Aplicație pentru companii care administrează săli și rezervări de evenimente. Acest repository conține aplicația React Native. Comenzile din ghidul frontend se rulează din rădăcina repository-ului.

Documentația comună este centralizată în [primary-docs](../primary-docs/README.md). Instalarea și pornirea sunt descrise în [FRONTEND.md](../primary-docs/FRONTEND.md); contractul actual și regulile sunt în [PROJECT_SCHEMA.md](PROJECT_SCHEMA.md) și [AGENTS.md](AGENTS.md).

Blocajele și probele pentru lansare sunt în [ROADMAP_LANSARE.md](../primary-docs/ROADMAP_LANSARE.md).

`primary-docs` este în workspace-ul părinte, în afara celor două repository-uri Git. Păstrează acest director alături de checkout-uri; commiturile API/frontend nu îl includ. Copiile locale AGENTS și PROJECT_SCHEMA sunt sincronizate cu sursele din documentația comună.
